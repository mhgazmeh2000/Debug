📖 راهنمای استفاده از نقشه‌ی معماری

این نقشه ساختار کامل پروژه‌ی Multi-Brand Printer Monitor را در سه نما نشان می‌دهد. هر گره یک «فایل/ماژول» واقعی پروژه است؛ روی هر گره کلیک کنید تا توضیح فارسی، مسیر دقیق فایل، و لیست فایل‌هایی که استفاده می‌کند و فایل‌هایی که از او استفاده می‌کنند نمایش داده شود.

🏗️ نمای معماری لایه‌ها

مسیر حرکت داده را از بالا به پایین نشان می‌دهد: از دستگاه‌های شبکه → لایه‌ی SNMP/HTTP → جمع‌آورنده‌ها (Collectors) → پردازش و وضعیت → ذخیره‌سازی → وب (Flask) → مرورگر کاربر.

🔄 نمای جریان داده

چرخه‌ی کامل دریافت اطلاعات را در ۱۳ مرحله‌ی شماره‌دار توضیح می‌دهد. با دکمه‌ی «▶ پخش» مراحل به‌ترتیب روشن می‌شوند و توضیح هر مرحله در پنل کناری نمایش داده می‌شود. سه «جریان فرعی» (سنسور، اسکن OID، اکشن‌های کاربر) هم پایین صفحه آمده‌اند.

🧩 نمای وابستگی فایل‌ها

۶۰ گره (همه‌ی فایل‌های پروژه + فایل‌های داده‌ی runtime + گره‌های بیرونی/تست)، ستون‌بندی‌شده بر اساس پوشه. پیکان A ─▶ B یعنی «A از B استفاده می‌کند (import)». خط‌های چین آبی = فراخوانی HTTP از فرانت‌اند، خط‌های نقطه‌چین بنفش = خواندن/نوشتن فایل، خط‌های چین خاکستری = تست.

⬇️ خروجی XML (draw.io)

  • دکمه‌ی «خروجی XML» یک فایل multi-printer-architecture.xml می‌سازد که هر سه نما را در سه صفحه‌ی جدا دارد.
  • در سایت app.diagrams.net (یا برنامه‌ی دسکتاپ draw.io) از مسیر File → Open فایل را باز کنید؛ هر سه صفحه قابل ویرایش و خروجی‌گرفتن (PDF/PNG/SVG) هستند.

🖱️ کنترل‌ها

  • کشیدن صفحه = جابه‌جایی · چرخ موس یا دکمه‌های ＋/－ = زوم · ⤢ = متناسب با صفحه (در نمای وابستگی حتماً زوم کنید)
  • هاور روی گره = هایلایت تمام اتصالاتش · کلیک روی چیپ‌های رنگی بالای صفحه = نمایش/پنهان‌کردن یک دسته
  • جستجو بر اساس نام فایل یا نام فارسی کار می‌کند.
